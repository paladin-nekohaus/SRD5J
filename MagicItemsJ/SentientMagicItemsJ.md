# 知性ある魔法のアイテム

一部の魔法のアイテムは知性と人格を持つ。そのようなアイテムは、以前の所有者の霊に取り憑かれていたり、作成時に使用された魔法によって自我を持っていたりするかもしれない。いずれにせよ、そのアイテムはキャラクターのように振る舞い、人格の癖、尊ぶもの、関わり深いもの、そして時には弱味まで備えている。知性あるアイテムは、使用者にとって大切にされる味方になることもあれば、常に悩みの種になることもある。

ほとんどの知性あるアイテムは武器である。他の種類のアイテムも知性を発現することがあるが、ポーションや巻物といった消費型のアイテムが知性を持つことは決してない。

知性ある魔法のアイテムは、GMが管理するNPCとして機能する。アイテムの起動する特性はすべて、使用者ではなくアイテム自身の制御下にある。使用者がアイテムと良好な関係を保っているかぎり、使用者は通常通りそれらの特性を利用できる。関係が悪化した場合、アイテムはその起動する特性を抑止したり、使用者に対してそれらの特性を向けたりすることさえある。

## 知性ある魔法のアイテムの作成

君が魔法のアイテムを知性あるものにすると決めた場合、ここで説明するいくつかの例外を除き、NPCを作成するのと同じ方法でアイテムの人格を作成する。

### 能力値

知性ある魔法のアイテムは、【知力】、【判断力】、【魅力】を持つ。君はアイテムの能力値を選ぶことも、ランダムに決定することもできる。ランダムに決定する場合、それぞれについて4d6をロールし、もっとも低い出目を取り除き、残りを合計する。

### 意思疎通

知性あるアイテムは、感情を共有したり、テレパシーで思考を伝えたり、声に出して話したりするなど、何らかの意思疎通の能力を持つ。君はそれがどのように意思疎通するかを選ぶか、以下の表でロールして決めることができる。

| d100   | 意思疎通手段                                                                                                                                                      |
|--------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 01-60  | アイテムは、それを運搬または使用しているクリーチャーに感情を伝えることで意思疎通する。                                                                             |
| 61-90  | アイテムは、1つ以上の言語を話し、読み、理解できる。                                                                                                    |
| 91-100 | アイテムは、1つ以上の言語を話し、読み、理解できる。加えて、アイテムはそれを運搬または使用している任意のキャラクターとテレパシーで意思疎通できる。 |

### 感覚

知性を持つと、周囲を認識できるようになる。知性あるアイテムは、限られた範囲まで周囲を知覚できる。君はその感覚を選ぶか、以下の表でロールして決めることができる。

| d4 | 感覚                                     |
|----|--------------------------------------------|
| 1  | 9m(30フィート)までの聴覚と通常の視覚。  |
| 2  | 18m(60フィート)までの聴覚と通常の視覚。   |
| 3  | 36m(120フィート)までの聴覚と通常の視覚。 |
| 4  | 36m(120フィート)までの聴覚と暗視。    |

### 特別な目的

君は知性あるアイテムに、おそらく他のすべてを排して追求する目的を与えることができる。使用者のアイテムの使い方がその特別な目的に沿っているかぎり、アイテムは協力的なままである。この方針から逸脱すると、使用者とアイテムの間に対立が生じる可能性があり、アイテムがその起動する特性の使用を妨げることさえある。君は特別な目的を選ぶか、以下の表でロールして決めることができる。

| 2   | *宿敵:* アイテムは、フィーンド、変身生物、トロル、ウィザードといった特定の種類のクリーチャーを打ち負かすか破壊しようとする。           |

### 対立

知性あるアイテムは、その人格と属性によって形作られた独自の意志を持つ。使用者がアイテムの属性や目的に反する行動をとった場合、対立が生じる可能性がある。そのような対立が生じた場合、アイテムは【魅力】判定を行ない、使用者の【魅力】判定と対抗する。アイテムが対抗判定に勝利した場合、アイテムは以下の要求の1つ以上を行なう。

- アイテムは、常に運搬されるか着用されることを要求する。
- アイテムは、アイテムが不快だと感じるものをすべて処分するよう使用者に要求する。
- アイテムは、他のすべての目的を排してアイテムの目的を追求するよう使用者に要求する。
- アイテムは、他の誰かに譲られることを要求する。使用者がアイテムの願いに従うことを拒否した場合、アイテムは以下のいずれか、またはすべてを行なうことができる。
- 使用者がアイテムと同調できないようにする。
- 起動する特性の1つ以上を抑止する。
- 使用者の制御を奪おうと試みる。

知性あるアイテムが使用者の制御を奪おうと試みる場合、使用者は難易度が(12+アイテムの【魅力】修正値)の【魅力】セーヴィング・スローを行なわなければならない。セーヴに失敗すると、使用者は1d12時間のあいだアイテムによって魅了状態になる。魅了状態であるあいだ、使用者はアイテムの命令に従おうとしなければならない。使用者がダメージを受けた場合、セーヴィング・スローを再ロールでき、成功すれば効果は終了する。使用者を制御しようとする試みが成功したか失敗したかにかかわらず、アイテムは次の夜明けまでこの能力を再び使用できない。
