# モンスターのデータ

モンスターのデータ（**データ・ブロック**と呼ばれることもある）は、君がそのモンスターを運用するために必要な不可欠な情報を提供する。

## サイズ分類

モンスターのサイズ分類は、超小型、小型、中型、大型、超大型、巨大のいずれかである。『サイズ分類』表は、特定のサイズのクリーチャーが戦闘においてどれだけのスペースを支配するかを示している。クリーチャーのサイズ分類とスペースに関する詳細については、『プレイヤーズ・ハンドブック』を参照すること。

**サイズ分類**

| サイズ分類 | スペース | 例 |
| ---------- | ---------------------- | ------------------- |
| 超小型 | 0.75×0.75m(2.5×2.5フィート) | インプ、スプライト |
| 小型 | 1.5×1.5m(5×5フィート) | ジャイアント・ラット、ゴブリン |
| 中型 | 1.5×1.5m(5×5フィート) | オーク、ワーウルフ |
| 大型 | 3×3m(10×10フィート) | ヒポグリフ、オーガ |
| 超大型 | 4.5×4.5m(15×15フィート) | ファイアー・ジャイアント、トリエント |
| 巨大 | 6×6m(20×20フィート)以上 | クラーケン、パープル・ワーム |
| | | |

> **クリーチャーの改造**
> 本書には多種多様なモンスターが収録されているが、冒険の一部に最適なクリーチャーを見つけるのに苦労するかもしれない。たとえば、別のモンスターから特徴を1つか2つ借りたり、本書にあるような**選択ルール**や**テンプレート**を使用したりして既存のクリーチャーを調整し、君にとってより使いやすいものにして構わない。モンスターを改造する場合（テンプレートを適用する場合を含む）、その脅威度が変化する可能性があることに留意すること。

## 種別

モンスターの種別は、その根本的な性質を表している。ゲーム内の特定の呪文、魔法のアイテム、クラス特徴、その他の効果は、特定の種別のクリーチャーに対して特殊な形で作用する。たとえば、*アロー・オヴ・ドラゴン・スレイイング*はドラゴンだけでなく、ドラゴン・タートルやワイヴァーンといったドラゴン種別の他のクリーチャーにも追加ダメージを与える。

ゲームには以下のモンスターの種別が含まれているが、これら自体に固有のルールはない。

**アンデッド**は、死霊術の魔法の行使や何らかの邪悪な呪いによって、恐るべき死せざる死の状態にもたらされた、かつて生きていたクリーチャーである。アンデッドには、ヴァンパイアやゾンビのような歩く死体だけでなく、ゴーストやスペクターのような肉体を持たない霊も含まれる。

**異形**はまったく異質な存在である。その多くは、世界の神秘的な力からではなく、そのクリーチャーの異質な精神から引き出された生得の魔法の能力を持っている。代表的な異形は、アボレス、スラード、ビホルダー、マインド・フレイヤーである。

**エレメンタル**は、元素界を故郷とするクリーチャーである。この種別のクリーチャーの中には、単にエレメンタルと呼ばれるクリーチャーを含め、それぞれの元素が動く塊にすぎないものもいる。元素のエネルギーを吹き込まれた生物的な形態を持つものもいる。ジンやイフリートを含むジンニーの種族は、元素界においてもっとも重要な文明を築いている。その他のエレメンタルのクリーチャーには、インヴィジブル・ストーカー、ウォーター・ウィアード、エイザーが含まれる。

**怪物**は、もっとも厳密な意味でのモンスターであり、普通ではなく、真に自然なものでもなく、ほとんど決して無害ではない恐ろしいクリーチャーである。魔法の実験が失敗した結果であるもの（アウルベアなど）もいれば、恐ろしい呪いの産物であるもの(ミノタウロスやユアンティなど)もいる。彼らは分類を拒み、ある意味では他のどの種別にも当てはまらないクリーチャーのための包括的な分類として機能している。

**巨人**は、ヒューマンやその同族を見下ろすほど背が高い。彼らは人間に似た姿をしているが、複数の頭部を持つもの(エティン)や奇形のもの(フォモール)もいる。本物の巨人族の6つの種類は、ヒル・ジャイアント、ストーン・ジャイアント、フロスト・ジャイアント、ファイアー・ジャイアント、クラウド・ジャイアント、ストーム・ジャイアントである。これらに加えて、オーガやトロルといったクリーチャーも巨人である。

**植物**はこの文脈において、普通の植物ではなく、植物のクリーチャーである。そのほとんどは歩き回り、中には肉食のものもいる。代表的な植物は、シャンブリング・マウンドとトリエントである。ガス・スポアやマイコニドといった菌類のクリーチャーもこの分類に含まれる。

**人造**は、生まれるのではなく作られるものである。創造者によって単純な動きに従うようプログラムされているものもあれば、知性を与えられ独立した思考が可能なものもある。ゴーレムは代表的な人造である。モドロンなど、外方次元界のメカヌスを故郷とするクリーチャーの多くは、より強力なクリーチャーの意志によってその次元界の素材から形作られた人造である。

**セレスチャル**は、上方次元界を故郷とするクリーチャーである。その多くは神々の使いであり、定命の領域やあらゆる次元界において、使者や代理者として使役されている。セレスチャルは本来善であるため、善の属性から外れた例外的なセレスチャルは恐るべき希少な存在である。セレスチャルには、エンジェル、コアトル、ペガサスが含まれる。

**ドラゴン**は、太古の起源と途方もない力を持つ、大型の爬虫類のようなクリーチャーである。善のメタリック・ドラゴンや悪のクロマティック・ドラゴンを含む本物のドラゴンは、高い知性を持ち、生得の魔法を持っている。また、ワイヴァーンやスードゥドラゴンのように、トゥルー・ドラゴンと遠い血縁関係にあるが、力や知性、魔法の力が劣るクリーチャーもこの分類に含まれる。

**粘体**は、決まった形を持つことがめったにないゼリー状のクリーチャーである。彼らは主に地下に生息し、洞窟やダンジョンに住み、ゴミや屍肉、あるいは運悪く彼らの行く手を阻んだクリーチャーを食べて生きている。ブラック・プディングやゼラチナス・キューブは、もっともよく知られているウーズの一部である。

**人型生物**は、ファンタジー・ゲームの世界の主要な人々であり、文明化されたものも野蛮なものもおり、ヒューマンやその他の非常に多様な種族が含まれる。彼らは言語と文化を持ち、生得の魔法の能力はあったとしてもわずかであり（ただし、ほとんどの人型生物は呪文発動を習得できる）、二足歩行の形態をしている。もっとも一般的な人型生物の種族は、プレイヤー・キャラクターとしてもっとも適したもの、すなわちヒューマン、ドワーフ、エルフ、ハーフリングである。それらとほぼ同数だが、はるかに野蛮で残忍であり、ほぼ一様に悪であるのが、ゴブリン類(ゴブリン、ホブゴブリン、バグベア)、オーク、ノール、リザードフォーク、コボルドの種族である。

**フィーンド**は、下方次元界を故郷とする邪悪なクリーチャーである。神々の使いであるものも少数いるが、さらに多くのものがアーチデヴィルやデーモン・プリンスの指導力の下で働いている。悪の司祭や魔道士は、自分たちの命令に従わせるためにフィーンドを物質界に召喚することがある。悪のセレスチャルが希少であるなら、善のフィーンドはほとんど考えられない。フィーンドには、デヴィル、デーモン、ヘル・ハウンド、ユーゴロス、ラクシャーサが含まれる。

**フェイ**は、自然の力と密接に結びついた魔法のクリーチャーである。彼らは薄明かりの木立ちや霧深い森に住んでいる。いくつかの世界では、彼らは妖精界とも呼ばれるフェイワイルドと密接に結びついている。外方次元界、特にアルボレアやビーストランズの次元界で見られるものもいる。フェイには、サテュロス、ドライアド、ピクシーが含まれる。

**野獣**は、ファンタジー世界の生態系の自然な一部である、人型生物ではないクリーチャーである。魔法の力を持つものもいるが、ほとんどは知性を持たず、社会や言語を持たない。野獣には、あらゆる種類の普通の動物、ディノサウルス、ジャイアント種の動物が含まれる。

### タグ

モンスターは、その種別の後ろの半角括弧内に1つ以上のタグが追加されている場合がある。たとえば、オークは*人型生物(オーク)*の種別を持つ。括弧内のタグは、特定のクリーチャーに対する追加の分類を提供する。タグ自体に固有のルールはないが、魔法のアイテムなど、ゲーム内の何かがそれらを参照する可能性がある。たとえば、デーモンと戦うのに特に効果的なスピアは、デーモンのタグを持つあらゆるモンスターに対して機能する。

## 属性

モンスターの属性は、その性質や、ロールプレイや戦闘の状況においてどのように振る舞うかの手がかりを提供する。たとえば、“混沌にして悪”のモンスターは理詰めで話をするのが難しく、キャラクターを見るとすぐに攻撃してくるかもしれないが、“真なる中立”のモンスターは喜んで交渉に応じるかもしれない。さまざまな属性の説明については、『プレイヤーズ・ハンドブック』を参照すること。

モンスターのデータ・ブロックに指定されている属性はデフォルトのものである。そこから逸脱し、君のキャンペーンの必要に合わせてモンスターの属性を変更して構わない。善の属性のグリーン・ドラゴンや悪のストーム・ジャイアントを望むなら、君を止めるものは何もない。

クリーチャーの中には、**任意の属性**を持つことができるものもいる。言い換えれば、君がそのモンスターの属性を選ぶ。一部のモンスターの属性の項目は、秩序、混沌、善、悪に対する傾向や嫌悪を示している。たとえば、狂戦士はその野性的な性質にふさわしく、任意の混沌の属性（“混沌にして善”、“混沌にして中立”、“混沌にして悪”）になることができる。

知性の低いクリーチャーの多くは、秩序や混沌、善や悪を理解していない。彼らは道徳的または倫理的な選択を行なうのではなく、本能に基づいて行動する。これらのクリーチャーは**無属性**であり、これは属性を持たないことを意味する。

## アーマー・クラス(AC)

鎧を着ているか盾を装備しているモンスターは、その鎧、盾、および【敏捷力】を考慮したアーマー・クラス(AC)を持つ。そうでない場合、モンスターのACは、その【敏捷力】修正値と外皮（もしあれば）に基づいている。モンスターが外皮を持つか、鎧を着ているか、盾を装備している場合、これはACの値の後の半角括弧内に記載される。

## ヒット・ポイント(hp)

モンスターは通常、ヒット・ポイントが0になると死ぬか破壊される。ヒット・ポイントに関する詳細については、『プレイヤーズ・ハンドブック』を参照すること。

モンスターのヒット・ポイントは、ダイス式と平均値の両方で提示される。たとえば、2d8のヒット・ポイントを持つモンスターは、平均して9のヒット・ポイントを持つ(2×4.5)。

『サイズ分類ごとのヒット・ダイス』表に示されているように、モンスターのサイズ分類によって、そのヒット・ポイントを計算するために使用されるダイスが決定される。

**サイズ分類ごとのヒット・ダイス**

| モンスターのサイズ分類 | ヒット・ダイス | ダイス1個あたりの平均HP |
|--------------|---------|--------------------|
| 超小型 | d4 | 2.5 |
| 小型 | d6 | 3.5 |
| 中型 | d8 | 4.5 |
| 大型 | d10 | 5.5 |
| 超大型 | d12 | 6.5 |
| 巨大 | d20 | 10.5 |

モンスターの【耐久力】修正値も、それが持つヒット・ポイントに影響を与える。その【耐久力】修正値は、それが持つヒット・ダイスの数と掛け合わされ、その結果がヒット・ポイントに足される。たとえば、モンスターが【耐久力】12（+1の修正値）と2d8のヒット・ダイスを持つ場合、それは2d8+2のヒット・ポイント（平均11）を持つ。

## 移動速度

モンスターの移動速度は、そのターンにどれだけ遠くまで移動できるかを示している。移動速度に関する詳細については、『プレイヤーズ・ハンドブック』を参照すること。

すべてのクリーチャーは歩行移動速度を持っており、単にモンスターの移動速度と呼ばれる。地上を移動する手段を持たないクリーチャーは、0m(0フィート)の歩行移動速度を持つ。

一部のクリーチャーは、以下の追加の移動手段を1つ以上持っている。

### 穴掘り

穴掘り移動速度を持つモンスターは、その移動速度を使用して砂、土、泥、または氷の中を移動できる。モンスターは、それを可能にする特殊な特徴を持たない限り、硬い岩の中を掘り進むことはできない。

### 水泳

水泳移動速度を持つモンスターは、水泳するために追加の移動速度を消費する必要はない。

### 登攀

登攀移動速度を持つモンスターは、自身の移動速度の全部または一部を使用して垂直な表面を移動できる。そのモンスターは登攀するために追加の移動速度を消費する必要はない。

### 飛行

飛行移動速度を持つモンスターは、自身の移動速度の全部または一部を使用して飛行できる。一部のモンスターは**ホバリング**能力を持っており、これにより空中で叩き落とされにくくなる（『プレイヤーズ・ハンドブック』の飛行に関するルールで説明されている通り）。そのようなモンスターは死ぬとホバリングするのをやめる。

## 能力値

すべてのモンスターは6つの能力値（【筋力】、【敏捷力】、【耐久力】、【知力】、【判断力】、【魅力】）と、それに対応する修正値を持っている。能力値とプレイでの使用方法に関する詳細については、『プレイヤーズ・ハンドブック』を参照すること。

## 技能

技能の項目は、1つ以上の技能に習熟しているモンスターのために用意されている。たとえば、非常に知覚が鋭く隠密行動に長けたモンスターは、【判断力】〈知覚〉判定と【敏捷力】〈隠密〉判定にボーナスを持つかもしれない。

技能のボーナスは、モンスターの関連する能力値修正値と、そのモンスターの脅威度によって決定される習熟ボーナス（『脅威度ごとの習熟ボーナス』表に示されている通り）の合計である。その他の修正値が適用される場合もある。たとえば、モンスターは高められた専門知識を反映するために、予想よりも大きなボーナス（通常は習熟ボーナスの2倍）を持つかもしれない。

> #### 鎧、武器、道具の習熟
>
> クリーチャーは自身の鎧、武器、道具に習熟しているとみなすこと。それらを交換する場合、そのクリーチャーが新しい装備品に習熟しているかどうかは君が決定する。
>
> たとえば、ヒル・ジャイアントは通常ハイド・アーマーを着てグレートクラブを振るう。君は代わりにヒル・ジャイアントにチェイン・メイルとグレートアックスを装備させ、その巨人が両方に習熟しているか、どちらか一方に習熟しているか、あるいはどちらにも習熟していないとみなすことができる。
>
> 習熟せずに鎧や武器を使用する場合のルールについては、『プレイヤーズ・ハンドブック』を参照すること。

## 脆弱性、抵抗、完全耐性

一部のクリーチャーは、特定の種類のダメージに対する脆弱性、抵抗、または完全耐性を持っている。特定のクリーチャーは、魔法的でない攻撃(魔法の攻撃とは、呪文、魔法のアイテム、またはその他の魔法の源によってもたらされる攻撃である)からのダメージに対してさえ抵抗や完全耐性を持っている。さらに、一部のクリーチャーは特定の状態に対する完全耐性を持っている。

## 感覚

感覚の項目には、モンスターの受動〈知覚〉値と、そのモンスターが持つかもしれない特殊な感覚が記載されている。特殊な感覚については以下で説明する。

### 暗視

暗視を持つモンスターは、特定の半径内の暗闇を見通すことができる。そのモンスターは、その半径内の“薄暗い”光の中を“明るい”光の中であるかのように見ることができ、“暗闇”の中を“薄暗い”光の中であるかのように見ることができる。そのモンスターは暗闇の中で色を識別することはできず、白黒の濃淡のみが見える。地下に生息する多くのクリーチャーがこの特殊な感覚を持っている。

### 擬似感覚

擬似感覚を持つモンスターは、特定の半径内において、視覚に頼ることなく周囲を感知できる。

グリムロックやグレイ・ウーズのような目を持たないクリーチャーは通常この特殊な感覚を持っており、バットやトゥルー・ドラゴンのような、音波探知や研ぎ澄まされた感覚を持つクリーチャーも同様である。

モンスターが生まれつき盲目である場合、その旨が半角括弧内に記載されており、その擬似感覚の半径がその知覚の最大範囲を定義していることを示している。

### 振動感知

振動感知を持つモンスターは、そのモンスターと振動の源が同じ地面や物質に接触している場合、特定の半径内にある振動の源を感知し、正確な位置を特定できる。振動感知は、飛行しているクリーチャーや実体のないクリーチャーを感知するためには使用できない。アンケグやアンバー・ハルクのような、穴掘りを行なう多くのクリーチャーがこの特殊な感覚を持っている。

### 超視覚

超視覚を持つモンスターは、特定の範囲まで、通常の暗闇および魔法の暗闇を見通し、不可視状態のクリーチャーや物体を見ることができ、視覚的な幻術を自動的に感知してそれらに対するセーヴィング・スローに成功し、変身生物や魔法によって変身させられたクリーチャーの本来の形態を知覚できる。さらに、そのモンスターは同じ範囲内のエーテル界を見通すことができる。

## 言語

モンスターが話すことができる言語はアイウエオ順に記載されている。モンスターが言語を理解できるが話すことができない場合があり、これはその項目に記載されている。「-」は、クリーチャーがいかなる言語も話さず理解もしないことを示している。

### テレパシー

テレパシーは、モンスターが指定された範囲内にいる別のクリーチャーと精神的に意思疎通を行なうことを可能にする魔法の能力である。接触されたクリーチャーは、この方法でそのモンスターと意思疎通を行なうためにそのモンスターと言語を共有している必要はないが、少なくとも1つの言語を理解できなければならない。テレパシーを持たないクリーチャーは、テレパシーによるメッセージを受け取り応答することはできるが、テレパシーによる会話を開始したり終了させたりすることはできない。

テレパシー持ちのモンスターは、接触したクリーチャーを見る必要はなく、いつでもテレパシーによる接触を終了させることができる。2体のクリーチャーが互いの範囲内にいなくなった場合、またはテレパシー持ちのモンスターが範囲内の別のクリーチャーに接触した場合、その接触は即座に途切れる。テレパシー持ちのモンスターはアクションを使用せずにテレパシーによる会話を開始または終了させることができるが、そのモンスターが無力状態であるあいだは、テレパシーによる接触を開始することはできず、現在の接触はすべて終了する。

*アンティマジック・フィールド*の効果範囲内、または魔法が機能しないその他の場所にいるクリーチャーは、テレパシーによるメッセージを送信したり受信したりすることはできない。

## 脅威度

モンスターの**脅威度**は、そのモンスターがどれほどの脅威であるかを示している。適切な装備を持ち十分に休息をとった4人の冒険者のパーティーは、自分たちのレベルに等しい脅威度を持つモンスターを、死者を出すことなく打ち倒すことができるはずである。たとえば、4人の3レベル・キャラクターのパーティーにとって、脅威度3のモンスターは手ごたえのある挑戦ではあるが、致命的なものではないはずである。

1レベル・キャラクターよりも著しく弱いモンスターは、1未満の脅威度を持つ。脅威度0のモンスターは、大群でない限り取るに足らない存在である。有効な攻撃を持たないものは経験値の価値がなく、攻撃を持つものはそれぞれ10XPの価値がある。

一部のモンスターは、典型的な20レベルのパーティーでさえ対処できないほどの大きな挑戦を提示する。これらのモンスターは21以上の脅威度を持ち、プレイヤーのスキルを試すために特別に設計されている。

### 経験点

モンスターが持つ経験点(XP)の価値は、その脅威度に基づいている。通常、経験点はそのモンスターを打ち倒したことに対して与えられるが、GMは他の何らかの方法でそのモンスターがもたらす脅威を無力化したことに対して経験点を与えることもできる。

別段の記載がない限り、呪文やその他の魔法の能力によって召喚されたモンスターは、そのデータ・ブロックに記載されている経験点の価値がある。

## 特徴

特徴(モンスターの脅威度の後、アクションやリアクションの前に記載される)は、戦闘遭遇において関連する可能性が高く、何らかの説明を必要とする特性である。

### 生得呪文発動能力

呪文を発動する生得の能力を持つモンスターは、生得呪文発動能力の特殊な特徴を持つ。別段の記載がない限り、1レベル以上の生得呪文は常にもっとも低いレベルで発動され、より高いレベルで発動することはできない。モンスターがレベルの重要となる初級呪文を持っており、レベルが指定されていない場合、そのモンスターの脅威度を使用すること。

生得呪文には特殊なルールや制限がある場合がある。たとえば、ドラウの魔道士は生得的に*レヴィテート*の呪文を発動できるが、この呪文には“自身のみ”という制限があり、これはこの呪文がドラウの魔道士自身にのみ影響を与えることを意味する。

モンスターの生得呪文を他の呪文と交換することはできない。モンスターの生得呪文が攻撃ロールを必要としない場合、それらに対する攻撃ボーナスは与えられない。

### 呪文発動能力

呪文発動能力の特殊な特徴を持つモンスターは、呪文の使い手としてのレベルと呪文スロットを持っており、これらを使用して1レベル以上の呪文を発動する(『プレイヤーズ・ハンドブック』で説明されている通り)。呪文の使い手としてのレベルは、その特徴に含まれるすべての初級呪文にも使用される。

そのモンスターは、特定のクラスから修得または準備した呪文のリストを持っている。そのリストには、クレリックの信仰の領域の特徴や、ドルイドのドルイドの円環の特徴など、そのクラスの特徴による呪文が含まれる場合もある。そのモンスターは、そのクラスの成員であること、またはその呪文リストへのアクセスを必要とする魔法のアイテムに同調したり使用したりする際、そのクラスの成員とみなされる。

モンスターは、そうするための呪文スロットを持っている場合、自身のリストにある呪文をより高いレベルで発動できる。たとえば、3レベルの*ライトニング・ボルト*の呪文を持つドラウの魔道士は、自身の5レベルの、その脅威度によって示唆されるよりも大きいまたは小さい脅威の1つを使用することで、それを5レベルの呪文として発動できる。

### サイオニック

自身の精神の力のみを使用して呪文を発動するモンスターは、その呪文発動能力または生得呪文発動能力の特殊な特徴にサイオニックのタグが追加されている。このタグ自体に特殊なルールはないが、ゲームの他の部分がそれを参照する可能性がある。このタグを持つモンスターは通常、呪文を発動するためにいかなる構成要素も必要としない。

## アクション

モンスターがアクションを行なう時、そのモンスターは自身のデータ・ブロックのアクションのセクションにあるオプションから選ぶか、『プレイヤーズ・ハンドブック』で説明されている“早足”や“隠れ身”のアクションなど、すべてのクリーチャーが利用できるアクションの1つを使用できる。

### 近接攻撃と遠隔攻撃

モンスターが戦闘において行なうもっとも一般的なアクションは、近接攻撃と遠隔攻撃である。これらは呪文攻撃または武器攻撃であり、ここでの“武器”は製造されたアイテムである場合もあれば、爪や尾のトゲのような肉体武器である場合もある。さまざまな種類の攻撃に関する詳細については、『プレイヤーズ・ハンドブック』を参照すること。

***クリーチャーと目標:*** 近接攻撃または遠隔攻撃の目標は通常、1体のクリーチャーまたは1つの目標のいずれかであり、その違いは“目標”がクリーチャーまたは物体になり得るということである。

***ヒット:*** 攻撃が目標にヒットした結果として与えられるダメージや発生するその他の効果は、*ヒット:*の表記の後に記載されている。君は平均ダメージを取るかダメージをロールするかのオプションを持っており、この理由から、平均ダメージとダイス式の両方が提示されている。

***ミス:*** 攻撃がミスした時に発生する効果を持つ場合、その情報は*ミス:*の表記の後に提示されている。

> #### モンスターの組みつきのルール
>
> 多くのモンスターは、素早く獲物につかみかかることを可能にする特殊な攻撃を持っている。モンスターがそのような攻撃をヒットさせた場合、その攻撃に別段の記載がない限り、組みつきが成功したかどうかを決定するための追加の能力値判定を行なう必要はない。
>
> そのモンスターによってつかみ状態にされたクリーチャーは、自身のアクションを使用して脱出を試みることができる。そうするためには、そのモンスターのデータ・ブロックにある脱出難易度に対する【筋力】〈運動〉判定または【敏捷力】〈軽業〉判定に成功しなければならない。脱出難易度が指定されていない場合、難易度は(10+そのモンスターの【筋力】〈運動〉修正値)であるとみなすこと。

### 複数回攻撃

自身のターンに複数の攻撃を行なうことができるクリーチャーは、“複数回攻撃”のアクションを持つ。クリーチャーは機会攻撃を行なう時に“複数回攻撃”を使用することはできず、機会攻撃は1回の近接攻撃でなければならない。

### 矢弾

モンスターは遠隔攻撃を行なうのに十分な矢弾を持ち運んでいる。君は、モンスターが投擲武器攻撃のための矢弾を2d4個、ボウやクロスボウのような射撃武器のための矢弾を2d10個持っているとみなすことができる。

## リアクション

モンスターが自身のリアクションで何か特別なことができる場合、その情報がここに含まれる。クリーチャーが特殊なリアクションを持たない場合、このセクションは存在しない。

## 回数制限つきの能力

一部の特殊な能力には、使用できる回数に制限がある。

***X/日:*** 「X/日」の表記は、特殊な能力をX回使用でき、消費した使用回数を回復するためにはモンスターが大休憩を終えなければならないことを意味する。たとえば、“1/日”は特殊な能力を1回使用でき、それを再び使用するためにはモンスターが大休憩を終えなければならないことを意味する。

***再チャージX-Y:*** “再チャージX-Y”の表記は、モンスターが特殊な能力を1回使用でき、その後、続く各戦闘ラウンド中にその能力がランダムな確率で再チャージされることを意味する。そのモンスターのそれぞれのターンの開始時に、1d6をロールする。そのロールが再チャージの表記にある数字のいずれかである場合、そのモンスターはその特殊な能力の使用回数を回復する。その能力はまた、モンスターが小休憩または大休憩を終えた時にも再チャージされる。

たとえば、“再チャージ5-6”は、モンスターがその特殊な能力を1回使用できることを意味する。その後、そのモンスターのターンの開始時に、1d6で5または6をロールした場合、その能力の使用回数を回復する。

***小休憩または大休憩の後に再チャージ:*** この表記は、モンスターが特殊な能力を1回使用でき、それを再び使用するためには小休憩または大休憩を終えなければならないことを意味する。

## 装備品

データ・ブロックが、モンスターが使用する鎧や武器以外の装備品に言及することはめったにない。人型生物のように習慣的に衣服を着るクリーチャーは、適切に服を着ているとみなされる。

君はモンスターに追加の装備や珍品奇品を好きなように装備させることができ、そのクリーチャーが殺された後にモンスターの装備品がどれだけ回収可能か、そしてその装備品のいずれかがまだ使用可能かどうかは君が決定する。たとえば、モンスターのために作られたボロボロの鎧が他の誰かによって使用できることはめったにない。

呪文を発動するモンスターが呪文を発動するために物質構成要素を必要とする場合、そのモンスターは自身のデータ・ブロックにある呪文を発動するために必要な物質構成要素を持っているとみなすこと。

# 伝説的クリーチャー

伝説的クリーチャーは、普通のクリーチャーにはできないことができる。自身のターンの外に特殊なアクションを行なうことができ、周囲何マイルにもわたって魔法の影響力を及ぼすかもしれない。

呪文などを通じてクリーチャーが伝説的クリーチャーの形態をとった場合、その形態の伝説的アクション、住処アクション、または地域効果を得ることはない。

## 伝説的アクション

伝説的クリーチャーは、自身のターンの外に、伝説的アクションと呼ばれる一定数の特殊なアクションを行なうことができる。一度に1つの伝説的アクションのオプションのみを使用でき、別のクリーチャーのターンの終了時にのみ使用できる。クリーチャーは自身のターンの開始時に、消費した伝説的アクションを回復する。それらを使用しないこともでき、無力状態であるか、その他の理由でアクションを行なえないあいだはそれらを使用できない。不意を打たれた場合、戦闘における自身の最初のターンの後までそれらを使用できない。

## 伝説的クリーチャーの住処

伝説的クリーチャーは、自身の住処と、そこにいるあいだに意志の力によって、あるいは単に存在することによって生み出すことができる特殊な効果を説明する項目を持っている場合がある。そのような項目は、自身の住処で多くの時間を過ごす伝説的クリーチャーにのみ適用される。

### 住処アクション

伝説的クリーチャーが住処アクションを持っている場合、それらを使用して自身の住処の周囲の魔法を利用できる。イニシアチブ20の時点(同値の場合は常に後回し)で、自身の住処アクションのオプションの1つを使用できる。無力状態であるか、その他の理由でアクションを行なえないあいだはそうすることはできない。不意を打たれた場合、戦闘における自身の最初のターンの後までそれらを使用できない。

### 環境に及ぼす効果

この項目に記載されているように、伝説的クリーチャーが単に存在すること自体が、その環境に奇妙で驚異的な効果をもたらす可能性がある。地域効果は、その伝説的クリーチャーが死ぬと突然終了するか、時間の経過とともに消散する。
