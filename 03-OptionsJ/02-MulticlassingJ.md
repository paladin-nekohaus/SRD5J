## マルチクラス
マルチクラスすることで、君は複数のクラスでレベルを得られるようになる。これにより、君は各クラスの能力を混ぜ合わせ、いつものようにクラスを1つ選ぶだけでは表現できないキャラクターを実現できるようになるのだ。

このルールを用いる場合、君はレベルアップするたびに、現在のクラスでレベルアップするか、新たなクラスのレベルを得るか選ぶことになる。君のキャラクター・レベルは、君が有するクラス・レベルの合計に等しい。たとえば、君が3レベルのウィザードで、かつ2レベルのファイターでもある場合、君は5レベルのキャラクターである。

レベルアップするにつれ、君は元のクラスにほとんど留まりながら他のクラスで多少レベルを重ねるかもしれず、あるいは、進路を全く変えて元のクラスのことは全く省みなくなるかもしれず、はたまた、3つ目4つ目のクラスに手を伸ばすかもしれない。1クラスしか持たないシングルクラス・キャラクターと比べると、君は多才さの代わりに専門性を失うことになる。

### 前提条件
新しいクラスを得るためには、『マルチクラスの前提条件』表に示されている通りに、現在のクラスと新しいクラスの両方で能力値の前提条件を満たさねばならない。たとえば、バーバリアンがドルイド・クラスにマルチクラスする場合、その【筋力】値と【判断力】値はどちらも13以上でなければならない。君は1レベルのキャラクターが経験しているようなしっかりした訓練を受けていないため、新しいクラスを素早く飲み込めばならない。前提条件となる平均以上の能力値は、そうするために必要な才能を表しているのだ。

| :------: | :----------------- |
| ウィザード  | 【知力】13            |
| ウォーロック | 【魅力】13            |
| クレリック  | 【判断力】13           |
| ソーサラー  | 【魅力】13            |
| ドルイド   | 【判断力】13           |
| バード    | 【魅力】13            |
| バーバリアン | 【筋力】13            |
| パラディン  | 【筋力】13または【魅力】13   |
| ファイター  | 【筋力】13または【敏捷力】13  |
| モンク    | 【敏捷力】13および【判断力】13 |
| レンジャー  | 【敏捷力】13および【判断力】13 |
| ローグ    | 【敏捷力】13           |

### 経験点
レベルアップに必要な経験点の量は『キャラクターの成長』表に書かれており、常に君のキャラクター・レベルの合計に基づいて決まる(特定のクラスのレベルではない)。したがって、君がクレリック6/ファイター1である場合、ファイターの2レベル目ないしクレリックの7レベル目を得るためには、8レベルに到達できるだけの経験点が必要になる。

### ヒット・ポイントとヒット・ダイス
君は、新しいクラスの"以降のヒット・ポイント"に示されている通りのヒット・ポイントを得る。"1レベル時点のヒット・ポイント"の項を参照するのは、君が1レベルのキャラクターである時だけだ。

君は自分が有する各クラスからもたらされたヒット・ダイスを集め、それをヒット・ダイスの総量とする。各クラスのヒット・ダイスが同じ種類であれば、君はただヒット・ダイスの数を合計するだけでいい。たとえば、ファイターとパラディンはどちらもヒット・ダイスがd10である。したがって、君がパラディン5/ファイター5である場合、君はヒット・ダイスとしてd10を10個有していることになる。一方、君のクラスがそれぞれ異なる種類のヒット・ダイスを持つ場合、それらは個別に記録せねばならない。たとえば、君がパラディン5/クレリック5である場合、君はd10のヒット・ダイスを5個、d8のヒット・ダイスを5個有していることになる。

### 習熟ボーナス
君の習熟ボーナスは『キャラクターの成長』表に書かれており、常にキャラクター・レベルの合計に基づいて決まる(特定のクラスのレベルではない)。たとえば、君がファイター3/ローグ2である場合、君は5レベルのキャラクターの習熟ボーナス、すなわち+3を持つ。

### 習熟
1レベル時点で選択したクラス以外のクラスで初めてレベルを得た時、君は『マルチクラスの習熟』表に書かれている通りに、その新しいクラスが1レベルでもたらす習熟の一部しか得られない。

### クラス特徴
新しいクラスでレベルを得た時、君はそのクラスのそのレベルで得られる特徴を全部得るが、新しいクラスの初期装備品を得るわけではない。くわえて、一部の特徴("神性伝導"、"追加攻撃"、"鎧わぬ守り"、"呪文発動")はマルチクラスに関する特殊なルールを持つ。

#### 神性伝導
君は、既に"神性伝導"の特徴を有している状態で他クラスのレベルを得、それが同じく"神性伝導"の特徴をもたらすレベルであった場合、君はそのクラスがもたらす"神性伝導"の効果を得るが、その使用回数が増加することはない。使用回数が増えるのは、"神性伝導"の使用回数が増えると書かれているクラス・レベルに達した場合だけだ。たとえば、君がクレリック6／パラディン4である場合、君のクレリック・レベルは"神性伝導"の使用回数が増えるレベルに達しているため、君は休憩と休憩の間に"神性伝導"を2回使用できる。また、君はこの特徴を使用するたびに、2つのクラスによってもたらされた効果から望むものを1つ選択できる。

#### 追加攻撃
複数のクラスから"追加攻撃"の特徴を得ていたとしても、それらが累積することはない。(ファイター版の"追加攻撃"のように)クラス特徴にそうできると書かれていない限り、このクラス特徴によって計3回以上の攻撃を行うことはできない。同様に、君が"追加攻撃"の特徴を有している場合、ウォーロックの妖術の1つである"血に飢えた剣"によって君の攻撃回数がさらに増えることはない。

#### 鎧わぬ守り
すでに"鎧わぬ守り"の特徴を有している場合、君は他クラスの"鎧わぬ守り"を得られない。

#### 呪文発動
君の呪文発動能力の"容量"は、部分的には君が持つ呪文発動クラスのレベルの合計に依存し、部分的には各クラスにおける君のレベルに依存する。複数のクラスから"呪文発動"の特徴を得ている場合、君は以下のルールに従う。マルチクラスしてはいるが、"呪文発動"の特徴を単一のクラスからしか得ていない場合、君はそのクラスに書かれている説明に従う。

**修得呪文と準備呪文**:君がどの呪文を修得していて、どの呪文を準備できるかは、──まるで君がシングル・クラスのキャラクターであるかのように──各クラスごとに決定される。たとえば、君がレンジャー4/ウィザード3である場合、君はレンジャー・クラスのレベルに基づいて1レベルのレンジャー呪文を3つ修得している。また、君は3レベルのウィザードとして、ウィザードの初級呪文を3つ修得しており、呪文書にはウィザード呪文が10個収められているが、そのうち(君が3レベルのウィザードになった時に得た)2つは2レベル呪文の可能性がある。そして、君の【知力】値が16であるなら、君は呪文書にあるウィザード呪文から6つを選んで準備できるということになる。　

君が修得ないし準備している呪文はすべて、君が持つクラスのうち1つに属している。そして、これらの呪文を発動する時、君はその呪文が属するクラスの呪文発動能力値を使用する。同様に、聖印をはじめとする呪文発動の焦点具は、その焦点具を用いるクラスに属する呪文を発動するためにのみ使用できる。

**呪文スロット**:君が使用できる呪文スロットは、君が持つ(1)ウィザード、クレリック、ソーサラー、ドルイド、バードのレベルと、(2)パラディン、レンジャーのレベルの半分(端数切り捨て)を全て足し合わせた値で決まる。この値を用い、『マルチクラスした呪文の使い手の呪文レベルごとの呪文スロット』表をもとに、自分が有する呪文スロットを確認すること。

君が呪文発動クラスを複数有している場合、この表によれば、修得も準備もできないほど高レベルな呪文スロットを得ることになる、ということもありえる。この場合、君はそのような呪文スロットを利用できるが、スロットより低いレベルの呪文を発動するためにしか使用できない。君が発動する低レベル呪文が、*バーニング・ハンズ*呪文のように"高レベル版"として発動することで効果が高まるものならば、──たとえ高レベルの呪文を一切有していなくても──君はその低レベル呪文で高い効果を得られる。

たとえば、君が前述の通りレンジャー4/ウィザード3であるなら、君は自分が使える呪文スロットを決定する時には5レベルのキャラクターとみなされ、1レベルの呪文スロットを4つ、2レベルの呪文スロットを3つ、3レベルの呪文スロットを2つ持っているが、3レベルの呪文を一切修得しておらず、レンジャー呪文に関しては2レベルのものさえ修得していない。君はこれらのレベルの呪文スロットを用いて自分が修得している呪文を──場合によっては効果が高まる"高レベル版"として──発動できる。

**契約による魔術**:"呪文発動"のクラス特徴とウォーロックの"契約による魔術"のクラス特徴を両方有している場合、君は"契約による魔術"の特徴で得た呪文スロットを使用して"呪文発動"のクラス特徴で修得ないし準備した呪文を発動することができ、"呪文発動"のクラス特徴で得た呪文スロットを使用して自分が修得しているウォーロック呪文を発動することができる。
