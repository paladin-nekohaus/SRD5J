
# 能力値の使用法
6つの能力値は各クリーチャーの肉体的、精神的な特質をざっくりと示すものである。

- **【筋力】** は肉体的な力の強さをはかる
- **【敏捷力】** は素早さをはかる
- **【耐久力】** は耐え忍ぶ力をはかる
- **【知力】** は論理的思考と記憶力をはかる
- **【判断力】** は知覚力と洞察力をはかる
- **【魅力】** は人格の力をはかる

そのキャラクターは筋骨隆々で洞察が深い人物だろうか、頭脳明晰で魅力的な人物だろうか、それとも、すばしっこくて頑健な人物だろうか？これらの性質、すなわちクリーチャーの得手(そして不得手)をあらわすのが能力値である。

このゲームには、上記の能力値6種にもとづいて行われる主要なダイスロールが3種類あり、それぞれ能力値判定、セーヴィング・スロー、攻撃ロールという。本書の"はじめに"の部分には、これらのダイスロールに共通する基本的なルールが書かれている。すなわち、d20を1つロールして、能力値6つのうちどれか1つにもとづく能力修正値をその出目に加え、その結果を目標値と比べる、というものである。

## 能力値と能力修正値
クリーチャーが持つ各能力値はそれぞれ数値を持つが、この値はその能力値の等級をあらわす。能力値は生まれつきの才能だけではなく、クリーチャーがその分野でどれだけ訓練を積み、どれだけ能力を向上させたまであらわす。

一般的なヒューマンは能力値の平均が10か11だが、冒険者や多くのモンスターはほとんどの能力値についてこの平均以上の値を持つ。能力値18は普通の人間が辿り着ける最高の値である。一方、冒険者の能力値は20が最高で、モンスターや神格は30が最高である。

各能力値は値のほかに修正値も持つ。この修正値は能力値から算出され、(能力値1の)−5から(能力値30の)+10までの値をとる。『能力値と修正値』表には、存在しえる能力値(1～30)と能力修正値の対応が示されている。

**能力値と修正値**

| 能力値　  | 修正値 |
| :---: | :-: |
|   1   | −5  |
|  2～3  | −4  |
|  4～5  | −3  |
|  6～7  | −2  |
|  8～9  | −1  |
| 10～11 | ±0  |
| 12～13 | +1  |
| 14～15 | +2  |
| 16～17 | +3  |
| 18～19 | +4  |
| 20～21 | +5  |
| 22～23 | +6  |
| 24～25 | +7  |
| 26～27 | +8  |
| 28～29 | +9  |
|  30   | +10 |

この表を見ずに能力修正値を求めたい場合は、能力値から10を引き、その結果を2で割ればよい(端数切り捨て)。

能力修正値はほとんどすべての攻撃ロール、能力値判定、セーヴィング・スローに作用する。したがって、ゲームのプレイ中、能力修正値はそれに対応する能力値そのものよりも頻繁に登場する。

## 有利と不利
時に、君は特別な能力や呪文によって、能力値判定、セーヴィング・スロー、攻撃ロールに有利ないし不利を得ることがある。そのような場合、君はそのダイスロールを行う時に2つ目のd20をロールし、有利を得ている場合は高い方の目を用い、不利を得ている場合はそのうち低い方の目を用いる。たとえば、君が不利を得ていて、d20の目が17と5だったなら、5の方を結果として用いる。一方、不利ではなく有利を得ている状態でこれらの目が出た場合は17の方を結果として用いる。

1つのロールに"有利ないし不利を与える状況"が複数存在する場合でも、君が追加でロールするd20は1つだけである。したがって、君に有利を与える要因が2つあったとしても、君が追加でロールするd20は1つだけだ。

複数の状況が1つのロールに有利と不利の両方をもたらす場合、君は有利も不利も得ていないものとして扱われ、d20を1つだけロールすることになる。このルールは、たとえば複数の状況が不利をもたらす一方、有利をもたらす状況は1つしかない場合でも変わりない(逆もまた然り)。つまり、このような状況において、君は有利も不利も得ていないのである。

君が有利ないし不利を得ているダイスロールにおいて、(ハーフリングが持つ"ハーフリングの幸運"をはじめとする)何かしらのゲーム的効果が君のd20を再ロールさせる場合、君は2つのd20のうちいずれか一方だけを再ロールする。どれを再ロールするかは君が選ぶ。たとえば、ハーフリングが有利ないし不利を得ている状態で能力値判定を行って1と13の目が出た場合、そのハーフリングは"ハーフリングの幸運"の特徴を使用して1が出たダイスを再ロールできるのだ。

君が有利や不利をえる要因は、特殊能力、アクション、呪文のいずれかであることが多いが、インスピレーションもキャラクターに有利を与える。くわえて、GMはその場の状況が特定の行為にプラスないしマイナスの影響を及ぼすと見なしたなら、そのダイスロールは有利ないし不利を受けると裁定することもできる。

## 習熟ボーナス
キャラクターはレベルにもとづく習熟ボーナスを有する。モンスターもこのボーナスを持ち、そのデータ・ブロックに既に組み込まれている。習熟ボーナスは能力値判定、セーヴィング・スロー、攻撃ロールに関連するルールで用いられる。

単一のダイス・ロールや単一のゲーム的値に習熟ボーナスが2回以上加算されることはない。たとえば、2つの異なるルールが、"君は自分の【判断力】セーヴィング・スローに自分の習熟ボーナスを加算できる"としている場合でも、君は【判断力】セーヴを行う時に習熟ボーナスを1回だけ足す。

場合によっては、君の習熟ボーナスはダイスロールに適用される前に増減することがある(2倍や半分になることが多い)。たとえば、ローグの"習熟強化"の特徴は特定の能力値判定に対する習熟ボーナスを2倍にする。単一のロールに習熟ボーナスを複数回適用できるような状況であっても、依然として習熟ボーナスを加算できるのは1回だけであり、習熟ボーナスの増減も1回だけ適用される。

同様に、何かしらの特徴や効果が特定の能力値判定に対する君の習熟ボーナスを増加させるが、そもそも君はその判定に習熟ボーナスを加えることができない、という状況の場合、君はその判定に習熟ボーナスを加えられない。その判定において、君の習熟ボーナスは0であって、0に何を掛けようが何で割ろうが0は0である。たとえば、君が〈歴史〉技能に習熟していない場合、君は"【知力】〈歴史〉判定を行う時、君の習熟ボーナスは2倍になる"という特徴を持っていても一切の利益を得られない

通常、攻撃ロールやセーヴィング・スローに対する君の習熟ボーナスが増加することは珍しいが、もしそのように書かれた特徴や効果が存在するなら、上記のルールはそれらにもそのまま適用される。

## 能力値判定
能力値判定は、キャラクターないしモンスターが困難を乗り越えようとする時に、その生得的な才能や訓練のほどを試すものである。キャラクターやモンスターが失敗する可能性のある行為(攻撃は例外)を試みた場合、GMは能力値判定を求める。困難を乗り越えられたかが不確かな時、その成否はダイスにゆだねられるのである。

能力値判定を行うたびに、GMは6つの能力値のうちその作業に対応しているのはどれかを判断し、その作業の難しさの度合いも決定する。この度合いは"難易度"として示される。作業が難しければ難しいほど、その難易度は高くなる。『典型的難易度』表にはよくある難易度が示されている。

**典型的難易度**

| 作業の難しさ  | 難易度 |
| :-------: | :---: |
| 非常に簡単   | 5   |
| 簡単      | 10  |
| 通常      | 15  |
| 困難      | 20  |
| 非常に困難   | 25  |
| ほとんど不可能 | 30  |

能力値判定を行うには、d20をロールして出た目に、対応する能力値の修正値を加算すること。それから他のd20ロールと同じ流れでボーナスとペナルティを適用したのち、その合計値を難易度と比べること。合計値が難易度と同じかそれ以上なら能力値判定は成功であり、クリーチャーは今回の挑戦を乗り越えたということになる。一方、合計値が難易度未満なら能力値判定は失敗である。しかし、失敗と一言で言っても、それはキャラクターやモンスターが何の成果も出せなかったことを意味する場合もあれば、成果は出るがGMが決めた何かしらの"つまづき"を被ることにもなったという場合もある。

### 対抗判定
時に、あるキャラクターないしモンスターの試みと、他者の試みが真っ向から衝突することがある。このようなことは、たとえば床に落ちた指輪を2人が拾おうとした時など、両者が同じことをしようとしたがそれに成功できるのはいずれか一方のみ、という場合にも起こる。また、モンスターがこじ開けようとしている扉を冒険者が閉じたままにしようとしている時など、一方がもう一方の目標達成を妨害しようとする場合もこれに該当する。このような状況の結果は"対抗判定"と呼ばれる特別な形態の能力値判定によって決まる。

対抗判定の参加者はそれぞれ自分の作業に対応する能力値判定を行って適切なボーナスとペナルティを適用するが、対抗判定ではその合計値を難易度と比較する代わりにお互いの合計値を比較しあう。そして合計値の高い方が対抗判定の勝者となり、勝った方のキャラクターないしモンスターはその試みに成功したか、相手が成功するのを妨害できたということになる。

対抗判定の結果が両者同値だった場合、状況は対抗判定の前から変化しない。これによってどちらか一方がなりゆきで対抗判定に勝利することもある。たとえば、キャラクター2人が床に落ちた指輪を拾おうとして対抗判定を行ったが結果が両者同値だった場合、どちらも指輪を拾うことはできない。けれども、モンスターがこじ開けようとしている扉を冒険者が閉じたままにしようとしていた場合、結果が両者同値なら扉は閉じたままになる。

### 技能
各能力値は能力や才能を大まかに表すもので、その能力や才能の中にはキャラクターやモンスターが習熟できる技能も含まれている。各技能は能力値の一側面を表すもので、一個人が特定の技能に習熟しているということは、その者がその側面へ特に打ち込んでいるということを意味する(キャラクターがゲーム開始時に習熟している技能はキャラクター作成時に決まり、モンスターの技能習熟はデータ・ブロックに書かれている)。

たとえば、キャラクタ―の試みのうち、(1)曲芸じみた軽業を成功させること、(2)物体をくすねること、(3)隠れて身をひそめることはいずれも【敏捷力】判定で表現される可能性があり、【敏捷力】はこれらの側面それぞれに対応する技能(順番にそれぞれ(1)〈軽業〉、(2)〈手先の早業〉、(3)〈隠密〉)を有している。したがって、〈隠密〉技能に習熟しているキャラクターは忍び歩きや隠れ身が特に秀でているということになる。

各能力値に対応する技能は以下の通り(【耐久力】に対応する技能は存在しない)。これら技能の使い方はこのセクションの後ろの方にある能力値の説明を参照すること。

#### 【筋力】
- 〈運動〉
#### 【敏捷力】
- 〈隠密〉
- 〈軽業〉
- 〈手先の早業〉
#### 【知力】
- 〈自然〉
- 〈宗教〉
- 〈捜査〉
- 〈魔法学〉
- 〈歴史〉
#### 【判断力】
- 〈医術〉
- 〈看破〉
- 〈生存〉
- 〈知覚〉
- 〈動物使い〉
#### 【魅力】
- 〈威圧〉
- 〈芸能〉
- 〈知覚〉
- 〈ペテン〉

時にGMは、「【判断力】〈知覚〉判定を行ってください」という具合に特定の技能を使用して能力値判定を行うよう求めることがあり、反対にプレイヤーの方から判定に特定の技能を使用できないかとGMへ尋ねることもある。どちらの場合であっても、ある技能に習熟している者はその技能を使用する能力値判定に習熟ボーナスを加えることができ、その技能に習熟していない者は普通の能力値判定を行うことになる。

たとえば、あるキャラクターが危険な崖を登ろうとする時、GMは【筋力】〈運動〉判定を行わせるかもしれない。この場合、キャラクターが〈運動〉技能に習熟していれば、それは【筋力】判定に習熟ボーナスを加えることができ、習熟していなければ普通通りの【筋力】判定を行うことになる。

#### 選択ルール:異なる能力値で技能を使う
普通、技能への習熟は特定の能力値判定にしか適用されない。たとえば〈運動〉技能への習熟であれば、それは【筋力】判定にしか適用されないのが普通だ。しかしながら、一部の状況においては、技能への習熟を別の種類の能力値へ適用することが道理にかなっている場合もある。このような場合、GMは普通とは違う能力値と技能の組み合わせで判定を行わせるかもしれないし、君の方から普通とは違う能力値での判定に習熟を適用できないかとGMに尋ねるかもしれない。たとえば、君が沖合いの小島から大陸まで遠泳しようとする場合、GMは君の気力がもつかどうか見るために【耐久力】判定を行わせるかもしれず、さらにGMは〈運動〉技能の習熟を適用してもよいと判断して、君に【耐久力】〈運動〉判定を行わせるかもしれない。この場合、君は〈運動〉技能に習熟していれば、(いつも通り【筋力】〈運動〉判定を行う時のように)【耐久力】判定に習熟ボーナスを加えることができる。これと同様に、君のハーフオークのバーバリアンが腕っぷしを誇示して敵を威圧しようとした場合、(普通〈威圧〉は【魅力】に対応しているものだが)GMは君に【筋力】〈威圧〉判定を行わせるかもしれない。

### 受動判定
受動判定は特殊な判定であり、ダイスロールを一切行わない。この種の判定は、(1)隠し扉がないかどうかをくまなく調べる時のように、何度も繰り返して行われる行為の平均的な結果を表す時や、(2)隠れているモンスターにキャラクターが気づくかどうかといった、キャラクターたちが何かに成功したかどうかをダイスロールなしで秘密裏に判断したい時に行われる。

キャラクターの受動判定の合計値は以下の式で求められる。

10+判定に通常適用される修正値全て

キャラクターがその判定に有利を得ている場合は+5し、不利を受けているv場合は−5すること。このゲームでは、受動判定の合計値は"受動～値"と呼ぶ。

たとえば、【判断力】が15で〈知覚〉技能に習熟している1レベル・キャラクターの場合、その受動【判断力】〈知覚〉値は14ということになる。

探険のルールと、"【敏捷力】"のセクションにある隠れ身のルールはこの受動判定を使用する。

### 協力
時に、2人以上のキャラクターが協力して1つの作業を成し遂げようとすることがある。その場合、キャラクターのうち、その作業を主導している──言い換えれば、より高い能力修正値を持つ──方が有利を得た状態で能力値判定を行うことができる。この有利には他のキャラクターの援護が反映されている。このようなことを戦闘中に行いたい場合は"援護"アクションが必要になる。

キャラクターは、自分一人で試みられる作業しか援護することができない。たとえば、錠前を解除するには盗賊道具への習熟が必要である。したがって、盗賊道具に習熟していないキャラクターは他のキャラクターが何かを解錠しようとする時に援護できない。くわえて、キャラクターが援護できるのは、複数人が協力することが確かに有意義であると言える場合だけだ。一部の作業、たとえば糸を針に通す作業は、援護すれば簡単になるような行為ではないだろう。

#### 集団判定
複数人が集団として何かを成し遂げようとする時、GMは集団判定を行わせることがある。その場合、特定の作業を得意とする者がそうでない者を助けることになる。

集団能力値判定を行う場合は、その集団に属する者全員が能力値判定を行う。そして、その半数以上が成功すれば集団全体が成功したことになり、そうでなければ集団全体が失敗したことになる。

集団判定は頻繁に行われるものではない。この種の判定が一番役立つのは、集団として全キャラクターが成功するか、さもなくば失敗するような時である。たとえば、冒険者たちが沼地を進む時、GMはキャラクターたちが流砂、水が浸食してできた穴など、沼地の環境に存在する自然の危険要因を回避できたかどうかを見るために集団【判断力】〈生存〉判定を行わせるかもしれない。集団の半数以上がこれに成功したなら、判定に成功したキャラクターは仲間たちが危険から逃れられるよう導いたということになる。さもなくば、集団は前述の危険要因のいずれかに誤って踏み込んでしまう。

## 各能力値の用法
ゲーム中にキャラクターやモンスターが試みる作業はみな、6つの能力値のうち1つに対応している。このセクションでは、これらの能力値がどんな意味を持ち、ゲーム中にどう使用されるかを詳しく説明する。

### 【筋力】
【筋力】は身体の力、運動に関する訓練、そして、君が純粋な物理的力をどれだけ生み出せるかをはかる尺度である。

#### 【筋力】判定
【筋力】判定は、何かを持ち上げたり、押したり引いたり、壊したりする時や、狭いスペースへ体を押し込んで通り抜ける時のような、状況を力ずくで突破するような試み全てに適用できる。〈運動〉技能は特定の【筋力】判定に適性があることを意味する。

**〈運動〉**:【筋力】〈運動〉判定は、登攀、跳躍、水泳のさなかで困難な状況に遭遇した時に使用する。このような活動の例は以下の通り。

- ほとんど垂直な崖や滑りやすい崖を登る。壁をよじ登っている最中に直面した危険を切り抜ける。他者が君を突き落とそうとする間、表面にしがみつき続ける。
- 尋常でない距離を跳躍する、跳躍中に離れ技を披露する。
- 危険な水流、嵐で荒ぶる大波、分厚い海藻が繁茂する海域のなかで必死に泳いだり、水面に浮き続けたりする。他のクリーチャーが君の泳ぎを妨害しようとして、君を水中へ押し込んだり引きずり込んだりしてきた時に抗う。

**その他の【筋力】判定**:上記以外にも、GMは君が以下のような作業を成し遂げようとする時に【筋力】判定を求めることだろう。

- たてつけが悪い扉、鍵やかんぬきがかけられた扉を強引にこじ開ける。
- 縄や拘束具を破壊する。
- あまりにも狭いトンネルをむりやり通り抜ける。
- 馬車の後ろに引きずられながらもそれにしがみつく。
- 像をひっくりかえす。
- 大きな岩が転がり出さないように抑える。

#### 攻撃ロールとダメージ
君はメイス、バトルアックス、ジャヴェリンといった近接武器で攻撃を行う時に、その攻撃ロールとダメージ・ロールに自分の【筋力】修正値を加えることができる。近接武器は白兵戦で近接攻撃を行うのに用いるが、中には投擲して遠隔攻撃を行えるものもある。

#### 持ち上げと運搬
君がどれだけの重量に耐えられるかは【筋力】値によって決まる。君が持ち上げられる重量ないし運搬できる重量は以下の用語によって言い表される。

**運搬能力**:君の運搬能力は(君の【筋力】×7.5kg(15ポンド)に等しい。運搬能力は君が運搬できる重量である。この値は十分高いため、この値を気にかける必要があるキャラクターはそう多くない。

**押し引きと持ち上げ**:君は運搬能力の2倍(言いかえれば【筋力】×15kg(30ポンド)までの重量を、押したり、引いたり、持ち上げたりすることができる。運搬能力を超過する重量を押し引きしている間、君の移動速度は1.5m(5㌳)にまで減少する。

**サイズ分類と運搬能力**:サイズ分類が大きいクリーチャーはより多くの重量にも耐えられる一方、超小型サイズのクリーチャーはより少ない重量しか運搬できない。サイズ分類が"中型"よりも1段階大きくなるたび、クリーチャーの運搬能力と、押したり、引いたり、持ち上げたりできる重量は2倍になる。一方、サイズ分類が"超小型"クリーチャーはこれらの重量が半分になる。

#### 選択ルール:荷重
持ち上げと運搬に関するルールが単純なのは意図的なものだが、"装備重量によってキャラクターがどれくらい不利を受けるかに関する"詳細なルールが欲しくなった時のために、以下の選択ルールも用意されている。この選択ルールを用いる場合、『防具』表にある【筋力】の部分は無視すること。

【筋力】値の5倍を超過する重量を運搬している場合、君には"**荷重**"がかかっている。"**荷重**"がかかっているということは、君の移動速度は3m(10㌳)減少するということを意味する。

【筋力】値の10倍を超過し、かつ運搬能力の上限以下の重量を運搬している場合、君には"**重荷重**"がかかっている。"**重荷重**"がかかっているということは、君の移動速度は6m(20㌳)減少し、君は【筋力】、【敏捷力】、【耐久力】を用いて行う能力値判定、攻撃ロール、セーヴィング・スローに不利を受けるということを意味する。

### 【敏捷力】
【敏捷力】は、機敏性、反射神経、平衡感覚をはかるものである。

#### 【敏捷力】判定
【敏捷力】判定は、器用に、素早く、あるいは静かに移動したり、足場が悪い場所から落ちずにいつづけたりするような試み全てに適用できる。〈隠密〉、〈軽業〉、〈手先の早業〉判定はそれぞれ、特定の【敏捷力】判定に適性があることを意味する。

**〈隠密〉**:【敏捷力】〈隠密〉判定は、敵から隠れる時、衛兵のそばをこっそり通り過ぎる時、気づかれないように退散する時、姿をさらさず、音も聞かせず、誰かに忍び寄る時に行う。

**〈軽業〉**:【敏捷力】〈軽業〉判定は、氷上を走る時、綱渡りの綱の上でバランスを保つ時、揺れる船の上でまっすぐ立ち続ける時のような、危うい状況で転ばないよう努める時に行う。

**〈手先の早業〉**:【敏捷力】〈手先の早業〉判定は、気づかれることなく他者の身辺に物を仕込む時、物を自分の身に隠す時のような、手先指先を駆使する行為を試みる時に行う。これ以外にもGMは、君が他者の財布をこっそり盗んだり、他者のポケットに物をすっと忍ばせる時にも【敏捷力】〈手先の早業〉判定を求めるだろう。

**その他の【敏捷力】判定**:上記以外にも、GMは君が以下のような作業を成し遂げようとする時に【敏捷力】判定を求めることだろう。

- 荷物で満載な馬車を操って急斜面を下る。
- 二輪戦車(チャリオット)を急旋回させる。
- 解錠を行う。
- 罠を無力化する。
- 縄抜けできないような方法で捕虜を縛る。
- じたばたして拘束から逃れる。
- 弦楽器を演奏する。
- 小さい物体や精密な物体を作成する。

#### 攻撃ロールとダメージ
君はスリング、ロングボウといった遠隔武器で攻撃を行う時に、その攻撃ロールとダメージ・ロールに自分の【敏捷力】修正値を加えることができる。くわえて、ダガーやレイピアなどの"妙技"特性を有する近接武器で攻撃を行う時にも、その攻撃ロールとダメージ・ロールに【敏捷力】修正値を加えることができる。

#### アーマー・クラス
着用している鎧次第ではあるが、君はアーマー・クラスに自分の【敏捷力】修正値の一部ないし全部を加算できる場合がある。

#### イニシアチブ
戦闘の開始時、君は【敏捷力】判定を行ってイニシアチブをロールする。戦闘中、各クリーチャーが行うターンの順番はこのイニシアチブによって決まる。

>**隠れ身**
>
>キャラクターが隠れ身を行える状況にいるかどうかはGMが判断する。隠れ身を試みる場合、君は【敏捷力】〈隠密〉判定を行う。君が発見されるか、君が隠れるのをやめるまで、この判定の合計値と"君の存在のしるしを積極的に見つけようとする各クリーチャーの【判断力】〈知覚〉判定"による対抗判定が行われ続ける。
>
>君は、君をはっきりと見ることができているクリーチャーから隠れることはできない。また、警告の叫び声をあげたり、花瓶をひっくり返すなどして大きな音を立てた場合、君は自分の居場所を露呈させてしまう。
>
>不可視状態のクリーチャーはいつでも隠れ身を行えるが、移動の兆候に気づかれる可能性は依然としてあるため、不可視状態のクリーチャーであっても音をたてないよう努める必要がある。
>
>戦闘中、クリーチャーの多くは周囲に危険がないかどうかに気を払うため、君が隠れ場所から移動して他のクリーチャーに接近した場合、相手は君を目にするのが普通である。それでも、特定の状況下において、GMは別のことに気を取られているクリーチャーの方へ隠れたまま近づいていくことを君に許可し、君が相手に見られる前に行う1回の攻撃に有利を与えるかもしれない。
>
>**受動〈知覚〉**:君が隠れている時、誰かが(たとえ能動的に探していなくても)君の存在に気づいてしまう可能性はある。そのようなクリーチャーが君に気づくかどうかを決定する時、GMは君の【敏捷力】〈隠密〉判定とそのクリーチャーの受動【判断力】〈知覚〉値(10+そのクリーチャーの【判断力】修正値にその他のボーナスやペナルティを加えたもの)を比較する。そのクリーチャーが判定に有利を得ている場合は+5し、不利を受けている場合は−5すること。たとえば、【判断力】が15(修正値は+2)で、〈知覚〉技能に習熟している1レベル・キャラクターの場合、その者の受動【判断力】〈知覚〉値は14ということになる。
>
>**何が見えて何が見えないか**:隠れているクリーチャーや物体が君から見えるかどうかを決定する主な要素の1つは、君がその範囲をどれぐらいよく見通せるかどうかであり、特定の範囲は"**軽度の隠蔽**"ないし"**重度の隠蔽**"を受けている。これらは"環境"のセクションで説明されている。

### 【耐久力】
【耐久力】は、健康さ、持久力、生命力をはかる尺度である。

#### 【耐久力】判定
【耐久力】判定を行う機会はあまり多くない。また、【耐久力】判定に対応する技能は存在しない。というのも、【耐久力】が表す持久力や忍耐力は主として受動的なものであり、キャラクターやモンスターが能動的に努力する類のものではないからである。けれども、君が普通の限界を超えて何かを試みる時、それは【耐久力】判定で表すことができる。

GMは君が以下のような作業を成し遂げようとする時に【耐久力】判定を求めることだろう。

- 息を止める。
- 休みなしで何時間も行進したり、労働したりする。
- 眠らずにすごす。
- 食料も水もなしで生存する。
- 大ジョッキ一杯分のエールを一息で空にする。

#### ヒット・ポイント
【耐久力】修正値はヒット・ポイントに作用する。通常、君はhpを決定するためにヒット・ダイスを1つロールするたび、その出目に【耐久力】修正値を加算する。

【耐久力】修正値が変動した場合、まるで1レベルの時から今と同じ修正値であったかのように、最大hpもそれに併せて変化する。たとえば、君が4レベルに達した時に【耐久力】を上昇させ、それによって君の【耐久力】修正値が+1から+2に上昇した場合、君は1～3レベルの分としてヒット・ポイントを3上昇させたのち、新しい修正値を使用して4レベル目のhpをロールすることになる。あるいは逆に、君が7レベルの時点で何かしらの効果が【耐久力】値を減少させ、それによって【耐久力】修正値も1減少した場合、君の最大hpは7減少することになる。

### 【知力】
【知力】は知性の鋭敏さ、記憶力の正確さ、論理的思考能力をはかる尺度である。

#### 【知力】判定
【知力】判定は、君が論理、受けた教育、記憶、演繹的推論を働かせる時に使用される。〈自然〉、〈宗教〉、〈捜査〉、〈魔法学〉、〈歴史〉技能はそれぞれ、特定の【敏捷力】判定に適性があることを意味する。

**〈自然〉**:【知力】〈自然〉判定は、地形、植物や動物、天候、自然の循環に関連する知識を思い出す能力をはかる。

**〈宗教〉**:【知力】〈宗教〉判定は、神格、儀式と祈祷、宗教的な位階制度、聖印、秘密の教団が持つ風習に関する知識を思い出す能力をはかる。

**〈捜査〉**:【知力】〈捜査〉判定は、君が証拠を探し回り、見つけた証拠をもとに推論する時に行う。また、どこにあるか分からない物体の場所を推測したり、傷口の見た目から用いられた凶器を判別したり、トンネルに存在する、"ここを壊せば全体が崩れる"という弱点を見抜く時もこの判定を用いる。さらに、古の巻物を熟読してそれに隠された知識の断片を探す時も【知力】〈捜査〉判定を求められる可能性がある。

**〈魔法学〉**:【知力】〈魔法学〉判定は、呪文、魔法のアイテム、奇怪なシンボル、魔法の伝承、諸次元界とその住人たちに関する知識を思い出す能力をはかる。

**〈歴史〉**:【知力】〈歴史〉判定は、歴史的出来事、伝説の人物、古の王国、過去にあった紛争や不和、最近起きた戦争、失われた文明に関する知識を思い出す能力をはかる。

**その他の【知力】判定**:上記以外にも、GMは君が以下のような作業を成し遂げようとする時に【知力】判定を求めることだろう。

- 言葉を用いずにクリーチャーと意思疎通を試みる
- 貴重なアイテムの値段を見積もる。
- 都市の衛兵になりすまそうとしている仲間にコツを教える。
- 文書を偽造する。
- 商工業にまつわる知識を思い出す。
- 技術が必要なゲームに勝つ。

#### 呪文発動能力値
ウィザードは呪文発動能力値として【知力】を用いる。また、ウィザードが発動する呪文のセーヴ難易度を決定する時は【知力】が用いられる。

### 【判断力】
【判断力】は、君が周囲の世界にどれだけ順応しているか、洞察力、直観力にどれだけ優れているかをはかるものである。

#### 【判断力】判定
【判断力】判定は、身振り手振りを見てその意味を察知したり、他者の気分を読んだり、周囲の事物に気づいたり、負傷者の手当てをしたりするような試み全てに適用できる。〈医術〉、〈看破〉、〈生存〉、〈知覚〉、〈動物使い〉技能はそれぞれ、特定の【判断力】判定に適性があることを意味する。

**〈医術〉**:【判断力】〈医術〉判定によって、君は瀕死の仲間を容体安定化させたり、病気の診断を試みることができる。

**〈看破〉**:【判断力】〈看破〉判定は、相手の嘘を見抜く時や次の行動を予測する時など、君が他のクリーチャーの真意を見極められたかどうかを決定する時に行う。この判定を行う時、君は相手のそぶり、話しの癖、態度の変化などを読み取って手がかりとする。

**〈生存〉**:【判断力】〈生存〉判定は、君が何者かの痕跡を辿ろうとする時、野生の獲物を狩る時、極寒の荒野で仲間を導く時、付近にアウルベアが生息していることを示す兆候を識別する時、天候を予測する時、流砂やその他の自然の危険を回避する時に行う。

**〈知覚〉**:【判断力】〈知覚〉判定によって、君は視覚、聴覚などなどを用いてなにがしかの存在を感知することができる。この判定は、君が周りの環境にどれだけ気を払っていて、その感覚がどれだけ鋭敏なのかをはかる。たとえば、閉ざされた扉の奥で交わされている会話に耳をすませる時、森の中をひそかに移動する怪物たちの音を聞き取る時、あるいは、道端で待ち伏せているオーク、小路の物陰に潜んでいる悪漢たち、隠し扉の隙間からこぼれるロウソクの明かりのように、隠されているものや見過ごされやすいものを発見する時に行われるのだ。

**〈動物使い〉**:君が家畜を落ち着かせる時、怯える乗騎をなだめる時、動物の意図を察する時、GMはその成否が定かでなければ君に【判断力】〈動物使い〉判定を求めることだろう。また、君は乗騎に危ない動きをさせようとして乗騎をうまく御そうと試みる時にも【判断力】〈動物使い〉判定を行うことになる。

**その他の【判断力】判定**:上記以外にも、GMは君が以下のような作業を成し遂げようとする時に【判断力】判定を求めることだろう。

- どう行動すべきかを直感的に判断する。
- 一見すると死んでいる／生きているクリーチャーがアンデッドかどうかを識別する。

#### 呪文発動能力
クレリック、ドルイド、レンジャーは呪文発動能力値として【判断力】を用いる。また、これらのクラスが発動する呪文のセーヴ難易度を決定する時は【判断力】が用いられる。

### 【魅力】
【魅力】は君が他者とうまく交流する能力をはかるものである。これには自信や雄弁さなどが含まれ、チャーミングな人柄、威風堂々たる人柄などをいずれも表し得る。

#### 【魅力】判定
【魅力】判定は、他者に影響を及ぼす時、他者を楽しませる時、自分の存在感を印象づける時、納得感がある嘘をつく時、厄介な社会的状況を切り抜ける時に行われる。〈威圧〉、〈芸能〉、〈説得〉、〈ペテン〉技能はそれぞれ、特定の【魅力】判定に適性があることを意味する。

**〈威圧〉**:君が公然の恫喝、敵対行動、肉体的な暴力で他者に影響を及ぼそうとする場合、たとえば、囚人から強引に情報を引き出す時、いざこざから手を引くよう街の悪漢を脅迫する時、嘲笑の笑みを浮かべる高官に割れた瓶の先を突きつけて考え直すよう迫る時、GMは君に【魅力】〈威圧〉判定を行わせることだろう。

**〈芸能〉**:【魅力】〈芸能〉判定は、音楽、踊り、演技、物語、その他の芸能によって観衆をどれくらい楽しませられたかを決定する時に行う。

**〈説得〉**:君が気配り、礼儀作法、気立ての良さで他者や人々に影響を及ぼそうとする場合、GMは君に【魅力】〈説得〉判定を行わせることだろう。基本的に、〈説得〉技能は君が善意で行動する場合、交流を深めたい場合、心からの頼みをする場合、然るべき礼儀を示す場合に用いられる。他者を説得する例としては、自分たちが王に謁見できるように侍従を納得させる時、争い合う両部族に交渉して講和させる時、町民たちを鼓舞する時などがある。

**〈ペテン〉**:【魅力】〈ペテン〉判定は、君が言葉や行動によって真実をうまく隠せるかどうかを決定する時に行う。この種の欺きには、情報を曖昧にして判断を誤らせることから、まったくの嘘までみな含まれる。〈ペテン〉技能を使用する典型的な状況としては、衛兵を言いくるめる、商人を騙して金を巻き上げる、賭博で金もうけする、変装して正体を見破られずにきりぬける、偽りの保証で他者の警戒を解く、大嘘を真顔で平然と言う、などがある。

**その他の【魅力】判定**:上記以外にも、GMは君が以下のような作業を成し遂げようとする時に【魅力】判定を求めることだろう。

- ニュース、噂、ゴシップを聞くのに一番適している人物を見つける。
- 人ごみに紛れて今流行りの話題が何かを把握する。

#### 呪文発動能力
ウォーロック、ソーサラー、バード、パラディンは呪文発動能力値として【魅力】を用いる。また、これらのクラスが発動する呪文のセーヴ難易度を決定する時は【魅力】が用いられる。

## セーヴィング・スロー
セーヴィング・スロー(単にセーヴと呼ばれることもある)は呪文、罠、毒、病気、およびそれらに類する脅威に抵抗する試みを表す。通常、自らの意思でセーヴィング・スローを行うことはなく、君は自分のキャラクターやモンスターが被害を受ける可能性がある場合にセーヴィング・スローを行うよう強制される。

セーヴィング・スローを行うには、d20をロールして出た目に、対応する能力地の修正値を加算すること。たとえば、【敏捷力】セーヴィング・スローを行う場合、君は【敏捷力】修正値を加算するのだ。

GMの判断次第でセーヴィング・スローには状況に応じたボーナスやペナルティが適用され、有利や不利の影響も加わる場合がある。

各クラスはそれぞれ、セーヴィング・スローに対する習熟を少なくとも2つもたらす。たとえば、ウィザードは【知力】セーヴに習熟する。技能への習熟と同様、あるセーヴィング・スローに習熟している者はその能力値を用いるセーヴィング・スローに習熟ボーナスを加えることができる。また、一部のモンスターもセーヴィング・スローに対する習熟を有している。

セーヴィング・スローの難易度はそれ引き起こした効果によって決まる。たとえば、呪文が行わせるセーヴィング・スローの難易度は、その呪文を発動した者の呪文発動能力値と習熟ボーナスによって決まる。

くわえて、セーヴィング・スローが失敗／成功した時の結果もそれを行わせた効果に記されている。通常、クリーチャーがセーヴに成功した場合、そのクリーチャーはその効果からの被害を全くを受けないか、失敗した場合と比べてより小さい被害しか受けずに済む。
